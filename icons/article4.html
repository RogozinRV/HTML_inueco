На главную
World Wide Web (WWW, Всемирная паутина)
Система связанных между собой документов, доступных через интернет. Концепция предложена Тимом Бернерсом-Ли в 1989 году для удобного обмена информацией посредством гиперссылок.
HTML
Язык гипертекстовой разметки — один из ключевых фундаментальных стандартов веба, созданный Тимом Бернерсом-Ли. Используется для структурирования содержимого веб-страниц.
HTTP
Протокол передачи гипертекста — ключевой стандарт веба, обеспечивающий обмен данными между клиентом и сервером.
URL
Унифицированный указатель ресурса — стандарт веба для адресации документов в сети, позволяющий однозначно идентифицировать любой ресурс в интернете.
WorldWideWeb (позже Nexus)
Первая в мире программа, разработанная Тимом Бернерсом-Ли на компьютере NeXT, которая одновременно являлась и веб-браузером для просмотра, и редактором для создания страниц.
CERN (ЦЕРН)
Европейская организация по ядерным исследованиям. Место, где Тим Бернерс-Ли работал консультантом и где официально представил проект WWW, а позже передал его исходный код в общественное достояние.
NeXT
Марка компьютера, за которым Тим Бернерс-Ли писал код и запускал первый в истории веб-сервер и браузер.
W3C (World Wide Web Consortium)
Консорциум Всемирной паутины — организация, основанная Тимом Бернерсом-Ли в октябре 1994 года. Занимается разработкой и поддержанием единых открытых стандартов для развития сети (включая HTML, CSS, XML).
CSS
Каскадные таблицы стилей — технология описания внешнего вида документа, разработанная под эгидой W3C.
XML
Расширяемый язык разметки — ещё один ключевой стандарт, разработанный под руководством W3C.
Solid
Проект, инициированный Тимом Бернерсом-Ли, направленный на децентрализацию веба и возвращение пользователям прямого контроля над их персональными данными, защищая их от монополии IT-корпораций.
Pod (Personal Online Data Store)
Изолированное персональное онлайн-хранилище данных в архитектуре проекта Solid, которым владеет и управляет исключительно сам пользователь.
